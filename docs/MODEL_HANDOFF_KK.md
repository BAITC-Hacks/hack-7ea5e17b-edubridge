# №2 моделін №1 және №3 қатысушыға қосу

**Күйі:** нақты дерекпен оқытылған пакет дайын. №1-дің `AgentService` және
`ModelBridge` модульдері арқылы нақты NOAA архивімен екі турбинаға 24/48 сағаттық
болжам тексерілді. Жаңа Python процесінде нәтиже қайталанды; бірдей кіріс ревизияны
өзгертпеді. Дәлелі: [model-integration.json](evidence/model-integration.json).

Таңдау кезеңінде `hgb_medium` ұтты (MAE **0,232464**). Кейінгі бөлек кезеңде
оның MAE-і **0,226919**, қарапайым жел қисығынікі **0,209460** болды. Бұл соңғы
кезеңде қарапайым модель жақсырақ. Таңдау алдын ала бекітілген tuning ережесімен
сақталды; ML тәсілі baseline-нан тұрақты жақсы деген қорытынды жасамаймыз.
Толық салыстыру: [model card](model-card.md).

## Берілетін файлдар

| Жол | Мазмұны |
|---|---|
| `models/wind-power-v1/model.joblib` | Екі турбинаның оқытылған моделі |

Пакет қайта оқыту кезінде басқа каталогқа сақталады. `metadata.json` немесе
салмақтарды қолмен өзгертуге болмайды: болжам алдында олардың сәйкестігі тексеріледі.

## №1: іске қосу

Командалар репозиторий түбірінен, Python 3.11 ортасында орындалады.
Windows-та `.venv/bin/python` орнына `.venv\Scripts\python.exe` қолданылады.

```sh
.venv/bin/python -m pip install -e '.[dev,weather,model]'
.venv/bin/python -m wind_agent --config config/archive-model.json health
.venv/bin/python -m wind_agent --config config/archive-model.json run --issue-time 2026-01-31T18:00:00Z --horizon-hours 48
.venv/bin/python -m wind_agent --config config/archive-model.json serve
```

API сипаттамасы: `http://127.0.0.1:8000/docs`. `health` конфигурация күйін көрсетеді;
модельдің жүктеліп, болжам бергенін `run` нәтижесі растайды. Ауа райы cache ішінде
болмаса, `run` NOAA архивінен дерек алады.

Нақты тексеруді бөлек қайталау:

```sh
.venv/bin/python scripts/validate_model_package.py --config config/archive-model.json
```

Бұл тексеру интернетке шықпайды; қажет ауа райы байттары
`artifacts/weather-training/cache` ішінде алдын ала болуы тиіс. Ол агенттің
нәтижесін тікелей модельмен және жаңа Python процесінде жүктелген модельмен
салыстырады. Есептің `status="passed"` мәні интеграцияны растайды, дәлдікті емес.
Бүкіл ақпан replay-і бұл тексеруге кірмейді.

## №3: нәтижені көрсету

Қаңтар метрикалары әзірге `models/wind-power-v1/validation.json` файлында беріледі.
Қазіргі `/evaluation` endpoint-і әлі `unavailable` қайтарады; файлдағы есепті API
мен интерфейске қосу — келесі командалық қадам.

- `prediction` бірлігі — **`normalized_power`**. MW/MWh деп жазбау және екі
  турбинаның мәнін станцияның MW қуаты ретінде қоспау керек: номиналдар мен
  нормалау формуласы берілмеген.
- `valid_time` — UTC бойынша сағат интервалының **соңы**. Мысалы, `19:00Z`
  `[18:00Z, 19:00Z)` сағатын білдіреді. Интерфейсте жергілікті уақытқа айналдырса,
  қолданылған уақыт белдеуін көрсету қажет.
- `lead_hours` қуат болжамының `issue_time` сәтінен саналады. Ауа райы моделінің
  өзінің lead мәнімен шатастырмау керек.
- `data_quality="warning"` және `warnings` мәтіндерін сақтап көрсету керек.
  Белгісіз уақыт шарттары қате болжам ретінде жасырылмайды.
- MAE/RMSE — нормаланған қуаттағы қате; оларды «дәлдік пайызы» деп атамау керек.
  Қаңтардағы holdout метрикалары соңғы production қайта оқытуына емес, holdout
  алдында бекітілген модельге қатысты.

## Ашық жорамалдар мен шектеулер

SCADA үшін әзірге тұрақты **UTC+5 (`Etc/GMT-5`)**, timestamp — 10 минуттық
интервалдың басы, қуат — сол интервалдың орташа мәні, жариялану кідірісі — 0 секунд
деп алынған. Бұл ұйымдастырушы растаған шарттар емес. `Asia/Almaty` тарихи
белдеуіне автоматты ауыстыруға болмайды: ол 2024 жылғы уақыт ауысуын қамтиды.
Оқытудағы барлық мәліметтің шегі — **2026-01-31 18:00 UTC**; осы сәттен кейін
белгілі болатын қаңтардың соңғы сағаты алғашқы модельге кірмейді.

Ауа райы — NOAA GFS архивтік болжамы: жел 100 м, температура 2 м, target сағатының
соңындағы сол сәттік мәндер. Оның қолжетімділігі архив объектілерінің metadata-сы
бойынша тексеріледі; бұл NOAA-ның бастапқы жариялау уақытын толық қалпына келтіру емес.
Екі турбина бір GFS тор ұяшығына түседі.

**Ақпанның нақты қуат деректері берілмеген.** Сондықтан ақпан болжамдары үшін
өлшенген MAE/RMSE немесе дәлдік көрсетілмейді. Сенімділік интервалдары калибрленбеген.
Болжам мен оқытуға LLM шақыруы, OpenAI API кілті немесе ақылы модель сервисі қажет емес.
