# Agentic AI для прогнозирования выработки ВЭС

Командный репозиторий HackAlem AI. Трек «Энергетика», владелец задачи — Самрук-Казына.

Цель: воспроизводимый прогноз почасовой выработки двух ветротурбин на 24–48 часов с ежедневным пересчётом для февраля 2026 года. Для каждого расчёта используются только данные и архивные выпуски прогноза погоды, доступные на тот момент.

**Текущий статус:** подготовлен план реализации для трёх участников. Приложение, модель, загрузчик погоды и команды их запуска пока не реализованы. Исторический датасет ещё не исследован.

- [План реализации: роли, ветки, задачи, контракты и приёмка](IMPLEMENTATION_PLAN.md)
- [Техническое задание организатора](https://docs.google.com/document/d/1Fn5IJoj87Fx7IAknG26zkfX8c0eq7feCujd0m66PCgY/preview?tab=t.0)
- [Правила хакатона](https://edu.astanahub.com/hackathons/df4743f5-c492-415c-b45a-1f13adb78e06?tab=regulations)

| Участник | Ответственность | Рабочая ветка |
| --- | --- | --- |
| №1 — текущий пользователь + Codex | Агент, погода, API, интеграция и воспроизводимость | `feat/agent-platform` |
| №2 | Данные, признаки, модель, временная валидация и метрики | `feat/forecast-model` |
| №3 | Интерфейс, графики, пользовательский сценарий и демо | `feat/dashboard-demo` |

Изменения поступают в `main` через pull request из рабочей ветки участника. Прямые push в `main` и force-push в общие ветки не входят в командный процесс. Это договорённость команды; серверная защита ветки этим PR не включается.

Перед сдачей участник №1 заменит статус выше на фактический и добавит проверенные инструкции установки, конфигурации, запуска, обучения, исторического пересчёта и проверки результата.
